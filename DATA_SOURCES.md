# Data Sources

Cosmopedia's mission information is compiled from public sources and stored in `assets/spacecraft.json`. Dates and details should be checked against the original source before being added or changed.

## Primary sources
- NASA NSSDCA Master Catalog: https://nssdc.gsfc.nasa.gov/
- NASA mission pages: https://www.nasa.gov/
- ISRO mission pages: https://www.isro.gov.in/
- ESA mission pages: https://www.esa.int/

## Secondary sources
- Wikipedia and Wikidata: https://www.wikipedia.org/ , https://www.wikidata.org/
  Wikipedia text is licensed CC BY-SA. If text from it is reused, give credit and use the same license for that text. Facts like dates can be checked against it, but descriptions in this project are written in our own words.

## Images
No images are included yet. NASA media is generally public domain, but check each image's usage notes. Images from other agencies or sites have their own licenses.

## Corrections
Found a mistake? Open an issue with the spacecraft name, the correct information and a link to a reliable source.
