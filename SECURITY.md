# Security Policy


VISIT IT:-

https://github.com/damu7341/cosmopedia
## Supported versions
Only the latest released version of Cosmopedia receives security fixes.

## Reporting a vulnerability
Please do **not** open a public issue for security problems.

Report privately in one of these ways:
- Use **Security → Report a vulnerability** on this repository's GitHub page, or
- Email [YOUR EMAIL] with the subject "Cosmopedia security".

Please include:
- A description of the problem
- Steps to reproduce it
- The app version and your Android version

You can expect a reply within about 7 days. Once the issue is fixed, you will be told, and credited if you wish.

## Keeping secrets safe
Signing keys (`*.jks`) and passwords must never be committed to this repository. They are stored in GitHub Secrets.
